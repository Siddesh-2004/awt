# Interview Experiences

Students share how their company interviews went; juniors read them before their own.

- **Frontend:** React 16.14, class components only (no hooks). JSX is compiled by the **Babel CLI**. No webpack.
- **Backend:** Node, Express, MongoDB (Mongoose).

## How the frontend gets built

```
src/app.jsx  --(Babel)-->  public/app.js  <--linked by--  public/index.html
```

Browsers can't read JSX, so Babel converts every `<Tag />` into a `React.createElement(...)` call
and writes plain JavaScript to `public/app.js`. `index.html` loads React, ReactDOM and then `app.js`.
Express serves the `public/` folder.

The long Babel command is wrapped in npm scripts so we don't type it every time:

| Command           | Runs                                    | What it does                                   |
|-------------------|-----------------------------------------|------------------------------------------------|
| `npm run compile` | `babel src --out-dir public`            | compiles JSX once                              |
| `npm run watch`   | `babel src --out-dir public --watch`    | recompiles every time `app.jsx` is saved       |
| `npm start`       | `node server/server.js`                 | starts Express (serves public/ + the API)      |
| `npm run dev`     | watch + server together                 | for development                                |

`babel.config.js` tells Babel which preset to use (`@babel/preset-react`, the JSX transform).

## Run it

Needs Node and a MongoDB connection (local or Atlas).

```
npm install
cp .env.example .env      # put your MONGO_URI in .env
npm run compile
npm start
```
Open http://localhost:5000

While developing: `npm run dev`, then refresh the browser after saving.

## Folders
```
babel.config.js     Babel settings
src/app.jsx         the React app (all components, JSX source)
public/index.html   page that loads React + app.js
public/style.css    minimal styling
public/app.js       generated by Babel - do not edit
server/             Express, Mongoose model, API routes
```

## API
| Method | Route                  | What it does               |
|--------|------------------------|----------------------------|
| GET    | /api/experiences       | list all, newest first     |
| GET    | /api/experiences/:id   | one experience             |
| POST   | /api/experiences       | publish a new experience   |

## React 16 features used
Class components, constructor/state/`setState` (incl. updater form), lifecycle methods
(`componentDidMount`, `componentDidUpdate`, `componentWillUnmount`), error boundaries
(`getDerivedStateFromError`, `componentDidCatch`), `Fragment`, `React.createRef`,
`PureComponent`, controlled form inputs. Pages are switched using the URL hash
(`#/`, `#/share`, `#/experience/<id>`) listened to in `App`.
